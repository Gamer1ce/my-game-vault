# 朋友语音频道

主页点击「语音频道」，进入独立页面，原游戏档案布局保持不变。当前仅在主站启用；Azure 备用站不发布此功能，也不运行语音中继。

## 怎么使用

1. 输入用户名和密码，点击「注册并登录」。不需要邮箱或验证码。
2. 用户名支持 3–24 个文字、数字、下划线和短横线；英文不区分大小写。密码至少 12 位，可以是一句好记的长句。请使用独立密码并保存在密码管理器里。
3. 右侧可修改展示昵称、个人简介、头像和面板颜色；点「保存面板」后其他频道成员就能看到。头像自动缩成小图，原图和图片元数据不保存。
4. 选择公共大厅、组队频道或深夜电台，点击「加入语音」，允许浏览器使用麦克风。每个频道最多 6 人。
5. 可单独关麦；「声音关」会同时关闭收听和麦克风，重新开启声音会保留你此前的独立静音选择。如果浏览器阻止自动播放，点击「点击启用声音」。
6. 点击「离开频道」停止通话并关闭麦克风。退出账号或关闭页面也会清理连接。同一账号只能同时加入一个频道；另一窗口加入会替换原有席位。

暂不提供密码自助找回，因为没有收集可验证的邮箱或手机。忘记密码需要联系站点维护者，不要把已有网站的管理员密码当成社区密码。普通社区用户没有游戏同步、接入密钥、AI 密钥、媒体管理或其他管理员权限。

## 网络与隐私边界

当前按站点拥有者选择，使用 **WebRTC 点对点语音**，不接 Azure、不提供 TURN 中继。网站服务器只处理账号、频道名单和连接协商；不会录音、转写，也不保存音频。使用公开 STUN 服务辅助发现可连通的地址。

点对点连接可能向同频道成员透露网络地址。不应把它当成匿名通信工具。语音媒体由 WebRTC 加密传输，但没有端到端身份认证指纹校验或 Discord 的完整安全与管理体系。

HTTPS 与麦克风权限是必需条件。对称 NAT、企业防火墙、某些手机流量网络可能无法互通；双方都能打开网页，不代表语音一定能连上。可以尝试切换 Wi-Fi / 移动网络、离开后重新加入。没有 TURN 时不能保证所有网络组合均可用。手机切到后台、锁屏或被系统节电限制时也可能断开。

## 自己部署

沿用项目现有 Node.js 24 / Docker 服务。安装依赖后设置：

```env
VOICE_COMMUNITY_ENABLED=1
```

或者在私密数据目录内创建一个空文件 `voice-enabled`，重启服务。未开启的实例返回功能不可用；不要给独立镜像实例同时开两套账号与频道。

- 页面：`/voice.html`；接口统一位于 `/api/voice/`。
- 账号、密码哈希、个人资料和登录会话存储在独立的 `data/voice.db`，不写入游戏数据库。
- 密码使用异步 scrypt（N=131072，r=8，p=1）及每用户随机盐，不保存明文。登录 Cookie 与管理员分开，HttpOnly、SameSite=Strict，HTTPS 下带 Secure，默认有效期 7 天；服务器只保存令牌哈希。
- 写入接口检查来源和 CSRF；注册、登录、图片编辑、信令有速率上限，密码计算限制并发。头像只允许实际可解码的 PNG / JPEG / WebP，重新编码为 WebP。
- 默认每 IP 每小时最多注册 5 个账号，全站每天最多 100 个；公共注册不是完整的反滥用系统，只适合小型朋友社区。
- 频道临时状态在内存中；服务器重启需要重新加入，但账号和资料保留。语音房间不因游戏数据库同步被替换。
- 反向代理需保持 SSE 流式响应，不要缓存或缓冲 `/api/voice/events`。麦克风权限只在语音页面开放，摄像头保持禁用。

### 备份

现有 Azure 游戏镜像脚本**不会复制 `voice.db`**。请将其单独加入私密备份，不要上传 GitHub；运行中 SQLite 应使用在线备份命令，而不是仅复制一个 `.db` 文件而漏掉 WAL：

```sh
sqlite3 data/voice.db ".backup '/你的私密备份目录/voice.db'"
```

本功能不引入付费服务。它是适合少量朋友的语音频道，并不包含 Discord 的服务器创建、文字聊天、私信、屏幕共享、角色权限、好友系统或大规模语音混流。
