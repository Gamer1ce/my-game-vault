# 用户登录与独立视频空间

首页的「用户登录」同时支持两种账号，但权限完全分开：

- 管理员：使用原有管理员账号与密码，在主页继续导入、连接与同步游戏数据。
- 视频用户：登录后进入 `/my-videos.html`，只查看分配给自己的视频库，没有游戏管理、平台凭据或 CPA 密钥权限。

网站视频账号由站长创建，不提供公开注册。语音频道现有的社区注册账号仍然独立，不能用于访问个人视频库。

## 两个硬盘

Docker 使用两个独立挂载：公开硬盘保持只读；戴卓然的私人硬盘允许写入，以便接收账号上传的视频。上传接口只能写入固定的私人目录，不能选择系统路径或覆盖原有视频。

| 用途 | 容器路径 | 主机配置 |
| --- | --- | --- |
| 主页公开精彩时刻 | `/media/highlights` | `GAME_VAULT_MEDIA_DIR` |
| 登录后个人视频 | `/media/private-dai` | `GAME_VAULT_PRIVATE_MEDIA_DIR` |

更换硬盘时修改以上路径并重新创建网站容器。不要把两个硬盘的共同父目录挂到公开媒体路径，也不要把私人文件复制进公开目录。现有视频不会因配置切换而搬动、转码或删除。

原始视频放在对应硬盘的任意非隐藏子文件夹中即可。主页显示公开硬盘里的视频和截图；个人页面读取自己的视频（MP4、WebM、MOV、M4V），支持搜索、按文件夹筛选、分批展开和播放。更新文件后点击「刷新片库」，目录缓存最多 10 秒。硬盘为空时显示空片库；离线时不回退读取别人的硬盘。

默认不复制原片到 Mac。缩略封面单独缓存在私密数据目录，公开与私人缓存分离。若硬盘已有 `.playback-cache` 无损分片，个人播放器可以使用；否则使用原文件的 Range 播放，不降低画质。是否流畅仍取决于上行带宽、文件码率及浏览器编码支持。

个人视频优先检测受保护的家庭 IPv6 直连，并保留本站兼容线路，不产生可绕过登录的公开分享地址，也不走已经停用的 Azure 线路。已下载或已缓冲到设备上的内容无法在退出登录后追回；后续新请求会重新校验权限。

## 私人原画播放

主站在登录后为选中的单个视频签发 30 秒有效、只能兑换一次的凭证。凭证只放在 HTTPS POST 请求体，不进入 URL、浏览器持久存储或访问日志。直连节点兑换后设置只属于自身主机和播放路径的 HttpOnly / Secure / SameSite=Strict Cookie，不扩大网站登录 Cookie 的域名范围。每次 Range 请求都会校验原网站会话、来源、有效期和文件范围；退出登录后拒绝新的请求。多标签页切换影片可能让旧标签回退兼容线路，但不会串播其他文件。

播放器验证直连和兼容线路的首尾 Range 后选择可用线路。小于等于 96 MiB 的短视频先完整缓存在内存并显示进度，播放时无需继续从公网下载；更大视频保留流式读取，尽量预缓冲 12 秒，可用时沿用无损 HLS 分片。不会转码降画质、写入本地存储或缓存到公共 CDN。关闭播放器会取消读取并释放内存，播放期间暂停背景封面加载。直连中断最多自动回退兼容线路一次，保留播放位置，不会反复切换；线路长期低于视频码率时，大文件仍可能等待缓冲。

当前直连使用 `steamway.gamer1ce.top:8443`。其他部署需要同步调整服务器允许的主站来源、直连 Origin 和播放器主机白名单。必须保持 HTTPS 和同站点子域；不要开放整个 `/api` 或把私人硬盘挂成静态目录。Caddy 的直连站点中仅补充：

```caddyfile
@privatePlayback path /api/private-playback/session /api/private-playback/file/*
handle @privatePlayback {
    reverse_proxy game-vault:4173
}
```

其他账号、管理及私人清单接口不通过直连域名公开。Safari 或移动网络无法使用跨子域播放会话 / IPv6 时自动使用主站认证线路。

## 戴卓然账号上传视频

使用戴卓然账号登录个人片库后，点击「上传视频」选择 MP4、MOV、M4V 或 WebM 文件，单个最大 8 GiB。文件按 4 MiB 分块上传，直接保存在私人硬盘的 `网站上传` 文件夹；临时分块位于隐藏目录 `.website-uploads`，不会出现在片库。服务器检查扩展名及容器文件头，完成后才发布到列表，不转码、不覆盖原文件。

上传显示进度，可暂停、继续或取消。网络中断后，在当前页面点击「继续上传」，会核对服务器已保存的偏移量后继续，不会重复追加分块。开始观看视频时自动暂停上传，关闭播放器后继续；手动暂停不会自动恢复。刷新、关闭页面或服务器重启后需要重新选择文件上传，不宣称支持跨重启断点续传。过期临时文件在 24 小时后由后台清理，不删除已完成的视频。

只有用户名为「戴卓然」且分配到私人片库的登录账号可调用上传接口，管理员和其他视频账号不能代替上传。所有上传写操作校验同源请求，每个分块重新检查登录身份；文件名不允许路径穿越，固定上传目录拒绝符号链接。一次只接收一个分块，最多保留两个任务，预留 1 GiB 空闲空间。上传不经过直连播放授权接口，也不开放公共上传地址。

私人列表复用已加载的封面卡片、搜索防抖并延迟渲染屏幕外卡片；上传完成立即刷新片库。播放器优先验证 IPv6 直连，不再同时等待兼容线路测速；缓冲进度显示限频，避免频繁更新页面。

纯本地模式下，公开媒体索引复用内存快照，快照超过 10 秒后在后台刷新，刷新期间继续显示上一份结果。硬盘扫描在独立线程执行，同一片库的并发请求合并为一次扫描，避免阻塞 HTTP 服务和视频传输。首次无快照时仍需等待硬盘扫描完成。管理员修改分类会清除快照，硬盘离线状态也会重新检查；展示状态按钮仍实时读取。

## 戴卓然账号删除视频

戴卓然登录个人片库后，每张视频卡片下方会显示「删除视频」。点击后会显示完整文件名并再次确认；确认后永久删除私人硬盘中的该原视频，无法撤销，请提前备份重要内容。支持删除硬盘中原有的视频和网站上传的视频，不删除其他文件或文件夹，也不涉及主页公开硬盘。

只有「戴卓然」且属于私人片库的会话可以删除，管理员、访客和其他账号均无此权限。服务端逐次校验登录身份、同源来源、视频格式、路径及文件版本，拒绝符号链接、隐藏目录、路径穿越和过期列表对应的已替换文件。删除后立即清除片库缓存，原片及其无损分片的新请求不可再读取；其他设备已经下载、缓冲或已开始传输的内容无法追回。封面缓存可能仍保留在服务器私密数据目录，但不能通过已删除视频的接口读取。

## 创建账号

在站点主机上运行以下命令，将占位用户名替换为实际用户名：

```sh
docker compose exec game-vault node scripts/create-media-user.mjs 你的用户名
```

命令只为当前个人片库创建账号，生成随机密码并显示一次。账号已存在时拒绝覆盖，不会悄悄重置密码。请安全交给账号本人，不要将密码写进 README、截图或 GitHub。

账号与会话保存在 `data/site-users.db`，与游戏数据库、语音社区数据库分开。数据库只保存 scrypt 密码哈希和会话令牌哈希；登录 Cookie 为 HttpOnly、SameSite=Strict，HTTPS 下带 Secure，8 小时到期。没有邮箱找回功能。

文件清单、封面、原片、HEAD / Range 请求以及 HLS 清单和分片，全部先检查当前会话及片库权限，响应禁止共享缓存。退出登录会撤销会话，不是仅隐藏页面。用户名猜测和跨站登录有速率与来源限制；文件路径拒绝穿越、隐藏目录与符号链接。

## Azure 备用站退役

当前主站已移除备用站入口，关闭 Azure 同步、远程同步请求轮询和镜像播放线路。现有 Azure 脚本保留在源码中供历史部署参考，但默认配置不再调用；不会重建被删除的虚拟机。

`AZURE_RETIRED=1`（或私密数据目录的 `azure-retired` 标记）会强制停用这些后台动作和镜像地址。`PUBLIC_MEDIA_LOCAL_ONLY=1`（或 `public-media-local-only` 标记）让首页只读取公开硬盘，不混入旧云端清单。重新使用其他存储前应先明确分配公开与私人文件范围。

SQLite 运行期间备份请使用在线备份命令，同时保护管理员配置及各账号库；不要把私密数据库和封面上传 GitHub。
